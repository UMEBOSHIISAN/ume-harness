# Human request presentation contract

Current flow: ordinary request -> interpretation -> deterministic clarification
and provisional action meaning -> Japanese preview -> stop. No worker, Lease,
authority token, external operation or completion receipt is produced.

Show what is proposed, which material questions remain, which human decisions
are suggested, and that operations have not executed. Avoid internal schema/tier
vocabulary in the normal report. Debug JSON is explicitly separate and advisory.
Errors in processing do not ask the human to rewrite an otherwise valid request.

Permission and failure hooks explain only their native event. Do not repeat raw
paths/arguments/queries/error bodies or convert explanation into allow/deny.
Host-native permissions, questions, worktrees, sessions and actual human authority
remain independent of UME. See contracts/task_intake.md for retained field meanings.
