# Japanese decision-support layer

The current CLI performs request interpretation and a deterministic pre-work
report. It does not execute the proposal. Its meaningful product logic is
clarification-impact processing, compound-action provenance and bounded Japanese
presentation; native language/output styles alone do not prove those semantics.
No comparative interpretation-quality or usability advantage has been measured.

intent_interpreter.md is the online prompt. Fixture material here is
REFERENCE_ONLY design material, not an interactive execution/approval/result flow.
The retained fixture test checks self-consistency, not model quality or live E2E.
See root README, SUPPORT_MATRIX and contracts/task_intake.md for current behavior.
